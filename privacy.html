Политика конфиденциальности

Дата вступления в силу: 25 октября 2026 г.

Эта политика описывает, какие данные собирает Telegram-бот @MyFNCbot (далее — «бот»), как он их использует и как вы можете их удалить.

1. Какие данные мы собираем

  • Данные Telegram: ваш числовой ID пользователя Telegram, имя и имя пользователя (username) — чтобы отличать ваши записи от записей других людей.
  • Настройки: валюта по умолчанию, бюджеты по категориям, ссылка на созданную для вас таблицу.
  • Финансовые записи, которые вы отправляете боту: сумма, категория, комментарий, дата.
  • Токен доступа Google — чтобы бот мог записывать данные в вашу таблицу.
  • Голосовые сообщения — только на время распознавания (см. раздел 4).

2. Доступ к Google и какие данные Google мы используем

Чтобы создать для вас таблицу, бот просит войти через Google и запрашивает только одно разрешение — https://www.googleapis.com/auth/drive.file. С ним бот:

  • создаёт на вашем Google Диске таблицу «Финансы — Ваше имя»;
  • записывает в неё ваши операции, отчёты и диаграммы;
  • имеет доступ только к файлам, которые создал сам. Другие файлы на вашем Диске бот не видит, не читает и не изменяет.

Бот хранит токен доступа Google, чтобы обновлять эту одну таблицу. Токен не используется ни для каких других целей.

3. Как мы используем данные

Данные используются только для работы бота: чтобы записывать операции, строить отчёты за месяц, считать бюджеты и синхронизировать вашу таблицу. Записи хранятся в базе данных бота, чтобы при сбое или повторном подключении таблицы ничего не потерялось.

4. Голосовые сообщения

Голосовые сообщения распознаются локально, на сервере бота. Аудио не передаётся третьим лицам и не сохраняется: после распознавания файл удаляется, остаётся только текст записи.

5. Передача данных третьим лицам

Мы не продаём ваши данные и не передаём их третьим лицам. Данные не используются для рекламы. Сообщения доставляются через Telegram, а таблица хранится в Google — эти сервисы работают по своим собственным правилам конфиденциальности.

6. Соответствие политике Google API (Limited Use)

Использование и передача ботом @MyFNCbot информации, полученной через Google API, другим приложениям соответствует Политике в отношении пользовательских данных сервисов Google API, включая требования об ограниченном использовании (Limited Use).

MyFNCbot's use and transfer to any other app of information received from Google APIs will adhere to Google API Services User Data Policy, including the Limited Use requirements.

7. Хранение и защита

Данные хранятся на сервере бота с ограниченным доступом и используются только для описанных выше целей. Мы храним их, пока вы пользуетесь ботом или пока вы не попросите их удалить.

8. Как удалить свои данные

  • Отозвать доступ Google: откройте myaccount.google.com/permissions, выберите приложение бота и нажмите «Удалить доступ». После этого бот больше не сможет записывать в вашу таблицу.
  • Удалить данные у бота: напишите боту @MyFNCbot, что хотите удалить свои данные, — владелец бота удалит ваши записи, настройки и токен.
  • Таблица находится на вашем Google Диске и принадлежит вам — вы можете удалить её сами в любой момент.
